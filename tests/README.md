# اختبارات محرر

## reviewed-examples.yml
أمثلة راجعها مالك المشروع واعتمدها أثناء إعداد 0.2.0.

## must-not-change.yml
حالات صممت خصيصا لمنع الإفراط في التصحيح.

## فلسفة الاختبار
لا نقيس النجاح بعدد التعديلات.

ترتيب النجاح:
1. ألا يفسد النص الصحيح.
2. ألا يغير المعنى.
3. ألا يغير حقيقة أو رقما أو درجة يقين.
4. أن يكتشف أثر الترجمة والحشو عندما يكونان فعليين.
5. أن يقترح بديلا طبيعيا عند وجود تحسين واضح.
